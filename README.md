# JDM HORIZON — V0.1

Мобильный 3D-прототип гоночной игры с японской атмосферой.

## Уже реализовано
- Процедурная тестовая локация: асфальтовая дорога, холмы, здания и стартовые ворота.
- Оригинальный условный JDM-купе автомобиль из простых 3D-мешей.
- Ускорение, тормоз, задний ход, поворот и ручник.
- Камера от третьего лица.
- Сенсорные кнопки и клавиатурное управление для тестирования.

## Запуск
1. Установите Godot 4.3 или новее.
2. Скачайте репозиторий или ZIP-архив.
3. В Godot выберите Import и укажите файл `project.godot`.
4. Нажмите Play.

## Управление на ПК
- W / стрелка вверх — газ
- S / стрелка вниз — тормоз / задний ход
- A, D — поворот
- Space — ручник / дрифт

На сенсорном экране используйте экранные кнопки.

## Сборка Android APK
Откройте проект в Godot на компьютере, установите Android Export Templates и настройте Android SDK/JDK в Editor Settings. Затем выберите Project → Export → Android.

## Ограничения V0.1
Это ранний игровой каркас, а не готовая Forza-подобная игра. Автомобиль и окружение пока процедурные заглушки: нет лицензированных моделей, сложной физики шин, трафика, миссий, сохранений и полноценной большой карты.
